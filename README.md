# 家庭药箱

面向家庭日常管理的共享药箱，用来记录药品、库存批次、有效期与存放位置，维护照护计划，并在用户确认后把资料导出给外部 AI。应用只做记录与资料整理，不诊断疾病，也不根据库存推断个人应当用药什么。

## 当前状态

已按 2026-10-14 的主线归一授权整合此前 PR3、PR4、PR5 的库存安全、多家庭、邀请、恢复门禁与界面修复。当前合并进度、精确版本和剩余卡点统一见 [当前状态](tasks/status.md) 与 [本次整合记录](docs/operations/24-RECEIPT-main-consolidation-20261014.md)。历史报告只对应其日期和提交，不再作为当前状态入口。

- 微信小程序 1.0.4；Flutter 1.0.3+6。数据库迁移文件已到 034，按文件名执行，不能只按编号判断是否全部应用。
- 单账号支持保留自建家庭并加入其他家庭，当前家庭按会话显式选择；服务端仍逐请求验证成员资格。
- 识别结果、资料候选和用途标签由用户核对，不自动保存、猜测用途或推断个人剂量。
- 项目仍为 **PARTIAL**。代码合并不等于服务器、手机、双账号设备、消息和正式签名验收；此前部署审批阻断与额外受限实验不因合并解除。

## 模块

- `apps/miniprogram/`：微信原生小程序，TypeScript、WXML、WXSS。
- `apps/flutter/`：Android 客户端；生产流程走家庭 API，演示流程位于 `/demo/*`。
- `apps/api/`：Fastify 服务、会话/家庭授权、库存和计划 API、识别与导出适配器、提醒调度器。
- `packages/contracts/`：前后端共享的类型契约。
- `apps/api/db/migrations/`：PostgreSQL 增量迁移。
- `docs/`：产品边界、当前架构、操作方法与验证记录。

## 本地开发

要求 Node.js 22 或更新版：

~~~powershell
npm ci
npm run lint
npm run typecheck
npm test
npm run build
~~~

本地 API/PostgreSQL 的隔离启动、健康检查和数据保护步骤见 `docs/operations/local-development.md`。真实微信账号、合法 HTTPS 域名和手机验收仍需单独完成。

## 当前候选阶段

当前 main 版本用于后续真实环境验收，不代表已发布。版本、签名、API origin、微信平台配置和目标数据库迁移必须在发布前按最终审核报告逐项核对。历史报告保留对应提交证据，但不得把旧测试计数、旧安装包或旧真机截图直接当作当前候选验收结果。

## 数据和安全边界

照片、库存与剂量备注属于需要保护的家庭健康信息。当前自动化验证仅使用合成数据。图片使用服务端鉴权和私有存储；模型与药品查询密钥只放在后端环境；后端每次按家庭检查权限。应用内的信息仅作药箱记录和来源核对，不能从库存或通用说明推断某个人应当用药。

## 微信开发者工具入口

开发源码默认访问本机 API。验证线上测试服务时，先生成独立配置，避免直接把源码项目当作线上预览：

~~~powershell
node scripts/prepare-miniprogram.mjs --appid wx1f6dd99d28aab8e5 --api-base https://medbox.joviluma.com
~~~

在开发者工具打开命令返回的目录；生成包保留域名校验且不含服务端密钥。服务端升级和契约检查未完成前不要上传或更新手机。
