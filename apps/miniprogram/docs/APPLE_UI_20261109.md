## 产品结构

保留「药箱 / 用药计划 / 我的」三项主导航，以及原生微信标题栏、返回、分享和订阅授权。家庭切换与邀请仍从药箱顶部和「我的 → 家庭管理」进入。

| 使用任务 | 本轮改动 | 原能力保留 |
| --- | --- | --- |
| 找药 | 搜索下方直接显示当前状态、用途/人群数量与排序名称；有条件时显示筛选摘要和结果数 | 药名、成分、厂家、位置搜索；原有排序及筛选规则 |
| 取消筛选 | 普通「重置筛选」保留搜索词；无匹配结果提供一次清除搜索与所有筛选的动作 | 不删除或改写药品、归档数据 |
| 读懂库存 | 在同一白色连续列表中展示名称、规格、余量、截止时间；状态既有语义色也有文字 | 过期、开封期限、未知数量与未知日期的业务判定 |
| 找回归档记录 | 默认统计只算未归档药品；全部记录已归档时，空态直接提供查看归档入口 | 更多状态内的归档筛选、详情归档/恢复逻辑 |
| 查看安排 | 切换日期后提供「回到今天」；空态区分今天/所选日期和是否已有计划 | 上海日期、前后台跨日处理、照护对象过滤、历史记录 |
| 切换日期 | 请求期间隐藏上一日期的安排和旧计划卡，不把旧安排显示在新日期标题下 | 请求代次、身份检查和不确定写入重试规则 |
| 记录服药 | 按钮可增高、操作行可换行，纠正说明独占一行 | 已服用/跳过、幂等重试、纠正确认与操作历史 |
| 管理资料 | 详情库存批次改成连续行；动作栏和导航栏通过既有 `embedded` 模式在同一页脚自然堆叠 | 批次、余量、说明书照片、私人备注、导出、家庭变更、删除 |
| 家庭与个人工具 | 「我的」使用设置式分组；家庭、邀请、盘点、补货、备份、回收站统一颜色 | 原有全部 26 页注册、设备授权、提醒与账号设置 |

“未归档”只表达记录状态。过期、用完、待核对的记录仍可未归档，因此界面不把这一集合称为“在用药品”，也不据此建议服用。

## 视觉与平台适配

- 共享颜色在 `app.wxss` 的 `--med-*` 定义。分组背景 `#F2F2F7`，白色内容层，主文字 `#1C1C1E`，次级文字 `#636366`，动作/选中态使用唯一品牌绿 `#087F5B`。
- 已有样式中的多种灰绿色统一到这些语义角色。独立组件引用提供字面 fallback，底部导航的真实颜色和原生 `tabBar` 配置由对比度测试交叉核对。
- 遵守项目已确认的中文紧凑档：首页标题 28，列表主文 16，正文 15，次级 13/12，最小注记 11（逻辑像素）。没有直接放大到西文默认 34/17。
- 高频按钮、筛选、搜索清除、日期切换、详情操作和分组入口以 48 逻辑像素为最小触控目标；允许文字换行后增高，保留 `safe-area-inset-bottom`。
- 首页与录入页移除装饰渐变、大面积绿色背景和多层阴影。内容卡不使用玻璃效果。
- 本轮小程序保持原有浅色系统配置。没有启用 `darkmode`，不能把设计预览的深色选项当作已完成的小程序深色验收。

## 代码边界

修改逻辑集中于首页和计划页的展示状态/导航动作。没有新增 `wx` 原生能力，也没有更改 API 方法、存储键、草稿生命周期、账户家庭隔离、用药剂量计算、备份恢复或数据库。

源码驱动预览是开发工具：`test/support/apple-ui-visual-preview.mjs` 读取当前 WXML/WXSS，以纯合成数据填充页面。`test` 目录已被发布打包规则排除。

# 有可运行 Chromium 的机器上，可生成截图与几何检查

该工具生成 390px/100% 和 320px/200% 文字两组，内容是当前源码合成状态。浏览器渲染与字号压力模拟不能替代微信原生、屏幕阅读器或真实手机验收。
