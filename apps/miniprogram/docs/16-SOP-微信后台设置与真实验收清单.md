# 微信后台设置与真实验收清单

状态：2026-10-07 main de74a585 已合并；平台配置尚未实读。用户截图/文本显示“隐私已更新、UGC未声明、订单path待设置、最低小程序版本未设置、最低基础库1.0.0、优先本地未设置”。这些是用户提供状态，不作为后台验收PASS。

| 设置 | 药箱当前实际能力 | 下一步与验收 |
|---|---|---|
| 用户隐私保护指引 | chooseMedia用于药盒/说明书；chooseMessageFile用于用户主动选择备份；库存/服药资料仅授权家庭可见 | 核对所选照片/文件说明、用途和保存/删除规则；真机首次同意/拒绝/再次授权及接口调用测试，不能仅看“已更新” |
| 用户生成内容场景 | 用户录入名称、规格、备注、照片及说明书，在授权家庭内共享；无公开社区、评论、直播 | 读取后台真实选项后选择对应私域文本/图片场景；不要声明不存在的公共发帖功能，最终声明由Owner核对 |
| 订单中心path | 源码无订单、支付及商品购买流程 | 不编造订单页；读取后台判断是否明确不适用或类目另有要求 |
| 最低可用小程序版本 | 当前平台是否有正式已发布版本未读；App1.0.3不能代替微信后台版本 | 有需阻断旧客户端的不兼容变更时才按真实已发布版本设置；先验证旧草稿/数据兼容 |
| 最低基础库 | chooseMedia、订阅消息、文件与隐私能力超过最早基础库范围 | 盘点API最低要求并以真机稳定SDK验收确定值；1.0.0不能证明兼容，不凭空填写未经验证的最低值 |
| 优先使用本地版本 | 已有草稿保护和失败延期更新 | 不是源码编译前置；先验升级兼容/离线行为再选择更新策略 |
| 屏蔽场景值 | 正常扫码预览、分享、家庭邀请需要可达 | 默认不额外屏蔽；除非有明确业务禁用场景，不盲目阻断入口 |

UGC场景文案草案：用户自行录入药品信息、库存批次、照片、说明书、备注及服药记录，内容仅本人和其授权家庭成员可见。小程序无公开社区、评论、直播及交易订单，不提供问诊或个体用药推荐。文案须与平台可选场景核对后再提交。

验收顺序：
1. 开发者工具客户端授权/扫码登录，核对当前账号可管理的AppID及JF小药箱对应关系；不得读取/索取AppSecret。
2. main精确CI全绿。隔离生成开发测试副本，源码“禁止上传”门禁保留；正式副本通过HTTPS/AppID/urlCheck/稳定基础库门禁。
3. IDE整包编译、质量检查和模拟器操作；编译/预览上传不当作真机通过。
4. 手机照片/文件隐私授权同意和拒绝；识别等待、失败重试、药名/规格人工核对、年月精度、保存后下一药空白。
5. 家庭切换、退出、迟到401/OCR、草稿重启恢复与双用户权限撤销。
6. 提醒真实送达、锁屏/重启、系统导出/分享、数据库与私照成对恢复。
7. 正式平台声明/签名/审核与部署；main合并不等同上线。

平台说明参考腾讯官方隐私适配文档：https://cloud.tencent.cn/document/product/1301/97930 。微信原始页面本轮无法由Web读取，相关最低版本及后台选项仍须官方IDE/后台实核。
