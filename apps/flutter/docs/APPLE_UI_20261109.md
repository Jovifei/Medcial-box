## 从实际操作中改善什么

| 用户任务 | 本次改变 | 业务边界 |
| --- | --- | --- |
| 找到家庭中的药品 | 导航栏以当前家庭名作为明确入口；搜索提示加入存放位置 | 仍使用已有药名、规格、成分、厂家、位置搜索数据 |
| 看懂为什么列表变少 | 展示当前搜索、用途、人群、状态和结果数量；「清除」同步清空输入框及筛选、恢复默认排序 | 保留筛选弹层，首页不重新铺满筛选胶囊 |
| 阅读长药名和大字号 | 长名称默认可显示两行；大字号下状态标签移至下一行、规格及数量／效期信息可换行 | 未知效期显示「日期待补充／效期待核对」，不再显示肯定的「有效」 |
| 断网或刷新失败后继续查看 | 有旧列表时明确说明正在显示上次读取内容并提供重试 | 仍保留原有离线与身份隔离机制，不承诺自动同步离线修改 |
| 管理家庭、提醒与设备 | `AppleListRow` 让标题、说明、辅助信息自然换行，长操作按钮可换行；触控区域至少 48 | 设置页全部原有操作继续调用原处理方法 |
| 从药箱回到家庭设置 | 点击当前家庭会进入「我的」并回到顶部家庭组 | 不再落在此前滚到页面底部的位置 |
| 找到归档记录 | 「我的 → 数据管理」新增已有归档页直达入口；采用系统风格导航 | 归档页仍是只读摘要，未增加恢复接口 |
| 查看今天的安排 | 展示待确认／已记录数量；加载失败可重试，有旧安排时明确标注 | 未读取成功时不显示“没有计划”；计数表示记录状态，不是服药依从性判断 |
| 使用系统大字号 | 系统缩放与 App 的小／标准／大档叠加；标准档保留系统完整缩放对象 | 不把系统非线性缩放曲线简化为一个线性倍率 |

## 视觉规则

- 保留 [DESIGN.md](../DESIGN.md) 已经收敛的 28／15 中文字阶，不整体放大字号。
- 分组内容保持实色；导航与控件层保留既有克制模糊，不新增装饰性玻璃卡片。
- 小号状态文字使用独立的 `dangerLabel`／`warningLabel` 深浅色语义前景，避免直接把浅色系统橙当小字颜色。
- 主按钮文字由组件主题解析正常、禁用、浅色和深色前景，不固定为白色。
- 筛选和字体选择弹层显式提供完整 `DefaultTextStyle`，避免在独立路由层继承调试用文字样式。
- `AppleListRow` 用于必须保留说明全文的分组行。它保留 Cupertino 按压反馈，补足系统单行列表在本工具长说明／大字号下的限制。

## 实现位置

- `lib/core/widgets/apple_list_row.dart`：48 最小点击区域、说明换行、长尾部动作自适应。
- `lib/features/home/production_shell.dart`：药箱搜索摘要、清除、状态提示、弹层和列表阅读。
- `lib/features/my/my_page.dart`：分组行、家庭定位、家庭读取重试、归档入口及字体选择弹层。
- `lib/features/medicine/archived_medicines_page.dart`：只读归档页面系统风格导航。
- `lib/features/plan/plans_page.dart`：加载状态和今天安排摘要。
- `lib/core/theme/font_scale.dart`、`lib/app.dart`：系统与 App 字号组合。
- `lib/core/theme/app_colors.dart`、`lib/core/widgets/app_surfaces.dart`：状态文字与主按钮语义前景。
