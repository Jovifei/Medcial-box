## 3. 本轮产品决策

### 药箱：让当前状态看得懂

视觉顺序为标题与家庭 → 搜索 → 需关注摘要 → 筛选/排序控制 → 已生效条件与结果数 → 连续药品列表。

筛选默认保持收起，避免重新摊开多个胶囊占用首屏。筛选以后必须看得见“当前筛了什么、按什么排序、剩几种”，并可直接清除。搜索结果为空、药箱本来为空、首次加载失败、刷新失败但有缓存是四种不同状态。

药品行首先回答药名、规格、余量、最早到期和位置。危险/警告状态必须有文字，不能只染色。日期未知不能显示为效期正常，数量未知不能计算成 0。药品列表中的“临期”描述库存状态，不是服用建议。

### 用药计划：日期明确，记录可纠正

保留“今日安排 / 全部计划”分段。切换到其他日期后，标题和空态都以选定日期为准，并有“回到今天”。不要在昨天的页面写“今天没有安排”，也不要把“这一天无安排”说成“从未创建计划”。

已服用/本次跳过属于单条安排的操作。记录成功在原条目回显；失败或结果不确定要保留重试语义，不能伪造成功。既有“纠正保留历史、不自动扣减库存”业务约定继续保留。

### 我的：按任务分组保全能力

推荐分组沿用现有业务：家庭与照护、药箱工具、数据管理、账号与设备、版本与帮助。家庭管理保留靠前位置；盘点、归档、补货、最近删除、变更记录、导出、备份等低频能力仍可发现。

大字号时标签、说明和值允许换行，不给整行固定高度。尾部箭头/开关保持可见，避免名称缩成无法识别的省略号。

### 次级流程：把业务差异说清

- **录入**：药名为必填，其他既有可选字段逐步完善；拍照和条码只是加速入口，识别需确认后保存。
- **详情**：库存和批次日期相邻，编辑信息与库存变更分开；避免“编辑药品”隐含扣减或新增批次。
- **邀请**：先呈现当前家庭、管理员身份、一次性/72 小时有效语义，再分享；接收方先预览家庭名称再确认加入。
- **最近删除**：展示药品/批次类型、删除日期、保留期限和恢复动作。归档、删除、过期处置含义不同，不合并成同一个“清理”。

## 4. 共同视觉约定

| 项目 | 约定 | 实现说明 |
| --- | --- | --- |
| 强调色 | 药箱绿 `#087F5B`；深色沿用 `#30B58B` | 主按钮、选中态、链接，不铺满内容区 |
| 分组背景 | 浅色 `#F2F2F7`，深色系统黑 | 页面背景，用于建立分组层级 |
| 内容表面 | 浅色白；深色 `#1C1C1E` | 连续列表和信息分组，不为每条加阴影 |
| 字号 | 28 / 24 / 20 / 18 / 16 / 15 / 14 / 13 / 12 / 11 | 遵守已确认中文紧凑档；必要时用 600 字重强调 |
| 字体 | 系统中文栈，PingFang SC / Noto Sans SC | App 沿用现有 `sans` 字体，不引入 Inter/Roboto |
| 间距 | 8 为主、4 为细分；页边 16–20、列表内 16 | 靠间距和分隔表达层级 |
| 圆角 | 常规信息分组约 12–14 | 既有约定 10–16，不做全屏巨圆角 |
| 触控 | 本轮目标 48×48；遵守既有最低 44×44 | 包括清除、返回、筛选、次级行操作 |
| 材质 | 只在导航与控制层克制使用 | 内容实色，避免玻璃背景影响药品信息阅读 |
| 状态 | 语义色 + 明确文案 + 需要时的图标 | 普通大小的彩色文本需单独检查对比度 |
| 大字号 | 主要内容可换行、卡片/行高自适应 | 不靠关闭 text scaling 来“通过”截图 |

参考稿的深色是设计对照，不自动代表所有客户端页面已经通过深色验收。渲染参考稿时可替换彩色文字为更深/浅的可读色；落地应走各端语义 token，不能散落新的 hex。

## 6. 验证界线

参考稿打开方式：直接打开 HTML。`?board=app` 是 App 四屏对照，`?board=mini` 是小程序四屏对照，`&theme=dark` 可用于深色对照。

应检查：320/390 下文字不重叠；200% 文字下可滚动和换行；搜索和筛选结果数正确；清除条件可恢复列表；请求失败与空药箱不混淆；切换日期后可回今天；表单必填反馈落到输入框；恢复后有可见结果。

### 本次实际核验结果

- JavaScript 语法检查：通过。
- `verify-reference.cjs` 的 11 项非浏览器状态/模板检查：通过，详情见 `reference-verification.json`。它们验证导航模板、筛选清除、必填和安全输出、日期与回今天、记录纠正、示例恢复等本地状态，不验证像素布局。

## 7. Apple 官方依据

以下原则用于解释布局决定；本项目字号、导航和品牌保留已确认的产品约定。

- [Materials](https://developer.apple.com/design/human-interface-guidelines/materials)：玻璃材料用于导航与控制层，应克制使用，内容层避免滥用。
- [Tab bars](https://developer.apple.com/design/human-interface-guidelines/tab-bars)：tab 服务主导航，入口稳定，图标配明确文字标签。
- [Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons)：易点的命中区域、清楚的主次操作及按压反馈。
- [Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility)：可调文字、颜色对比、足够的控件尺寸与间距。
- [Larger Text evaluation criteria](https://developer.apple.com/help/app-store-connect/manage-app-accessibility/larger-text-evaluation-criteria)：验证 200% 或系统最大字号；避免严重截断/重叠，横排必要时改纵排。

本轮研究没有获取用户个人健康数据。药名、日期、家庭与邀请码均为可复现的示例，不表达剂量建议。
