# 1.0.6 小程序下一阶段发布验收计划

日期：2026-10-21。基于 E 盘原仓库 `48eb89455e6dcddd147337c1983b9c056f2b0447` 的只读检查，以及同一小药箱网页端 ChatGPT 会话的第 23 轮独立方案。本文是执行计划，不是发布回执。

- 2026-10-13 的 `blocked by policy` 是一次本机命令启动前拒绝，不能推断今天所有部署均被禁止；不重放该原命令。已运行的后端无需重部署。

## 执行顺序与验收门槛

| 阶段 | 执行与交付 | 通过条件 / 停止条件 |
| --- | --- | --- |
| P0 固定身份 | 本地 Codex 只读记录源码 SHA、小程序 tree、版本、线上完整镜像与容器 ID、卷身份、迁移、备份时间和公网状态；生成脱敏基线。 | 镜像、卷、迁移或来源不一致即停。保持 `031` 和所有既有文件。 |
| P1 数据可恢复 | 在与生产完全隔离的环境恢复升级前成对数据库和照片归档，核对备份时两家庭稳定 ID、成员/owner、所有业务表计数及关联、照片文件与引用；如需验证 31→36，须在恢复副本上单独迁移并再核对。只输出脱敏摘要。 | 恢复、关联、照片或家庭归属任一失败，禁止真实家庭写入测试。保留两份原备份；不覆盖生产库。 |
| P2 网络与微信前置 | 本地核 TLS、证书链、DNS、HTTPS 路由、图片请求体与超时；核后端 AppID 是否与微信后台一致，仅检查 AppSecret 是否配置。微信后台核 `request`、`downloadFile` 合法域名、主体、备案、类目、隐私和体验者权限。 | 域名校验关闭、AppID 不符、证书/权限异常即停。`ready 200` 不能替代真实微信登录。 |
| P3 固定候选 | 从固定源码运行 `scripts/prepare-miniprogram.mjs`，生成 `.local-data/mini-staging-*` 的正式 HTTPS 副本；运行 `scripts/check-miniprogram-package.mjs`，记录包指纹、AppID、API origin、版本和基础库。 | 只能使用隔离副本；本机地址、测试标记、私有文件、关域名校验或包检查失败即停。 |
| P4 开发者工具联调 | 在微信开发者工具打开 P3 副本并实际编译，检查登录、导航、家庭入口、拍照扫码入口、照片回显及真实 HTTPS 请求；收集脱敏 Network/控制台回执。 | 不以仓库源码静态检查冒充生成副本编译。发现本机请求、旧身份、令牌泄漏或接口不兼容即停。 |
| P5 体验版 | 对通过 P3/P4 的精确候选上传开发版本、核微信平台版本指纹、限定体验成员并生成体验码。 | 上传成功只代表平台接收，不代表功能通过。候选指纹或账号不一致即停。 |
| P6 双家庭 | 两个获授权微信身份实测登录、家庭列表/切换、邀请冷启动与首页返回、加入、会话过期、弱网及晚到响应；越权访问另一家庭的药品/照片必须被拒。退出、撤权等破坏性场景先用隔离环境。 | 原两家庭稳定 ID 与原资料保留；错家展示/写入或越权读取即停。授权新增成员需记录合法变化，不机械要求总数恒为 2。 |
| P7 拍扫保存闭环 | 真机实测拍药盒、效期、说明书、待确认草稿、人工修正、保存药品/批次/私照、关闭页面与冷启动重开；扫码分别记录读码、本地命中和无匹配；测试超时、拒权、重试及跨家晚到响应。 | 真实照片必须从服务端重新读取；不重复保存、不丢照片、不跨家、不自动确认。`local` 资料源未命中不能当扫码器故障，也不能承诺全网条码匹配。 |
| P8 平台审核材料 | 对照实际功能核微信隐私指引、相机相册权限、服务类目、演示路径与客服说明；使用独立演示身份及合成资料供审核。 | 不向审核人员提供两个真实家庭的私有凭据或照片。资质/隐私不匹配即停。 |
| P9 审核与发布 | 体验版强制用例与独立复审通过后提交微信审核；平台审核通过后固定版本，由 Jovi 决定正式发布；发布后再做普通微信环境回归。 | 体验通过、提交审核、审核通过、正式发布和发布后验证分别记状态。任何修复须重建候选并重验相关门槛。 |

P0–P4 可以先开展不写真实家庭数据的工作。P1 通过前不进行真实家庭写入；P6/P7 的生产最小写入需限定测试身份与数据范围。后端部署、微信体验上传、正式审核和发布分开记录；Android 正式签名是 Android 交付门槛，不是 iPhone 微信体验版前置条件。

## 本阶段最小交付

依次形成脱敏的基线、隔离恢复、HTTPS/微信后台、候选包、开发者工具、微信上传、两家庭、拍扫闭环和平台审核回执；每项写明实测时间、执行者、精确源码/包指纹、`PASS/FAIL/NOT_RUN` 与停止原因。真实数据库、家庭明细、照片、令牌和密钥不进入 GitHub 或聊天。已部署 API 保持运行，两个既有家庭和数据必须保留。

本轮只制定计划并核对源码/线上只读事实；未生成新包、未上传微信、未操作生产数据。网页端第 23 轮方案将后端与微信发布分轨，本地对升级前备份迁移口径作了修正。下一轮从 P0/P1/P2 的证据核验与 P3 候选准备开始，不把计划当作上线验收。
