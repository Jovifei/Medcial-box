# 49 号回执：朋友反馈修复批次（2026-10-25）

分支 `codex/medbox-friend-feedback-20261025`（自 main `9ee94f7`），最终以本文记录的提交为准。Jovi 反馈三项，全部修复并按其产品决定更新了两条既往保守规则（见决策记录）。

## 修复内容

1. **保存成功后不再残留草稿提醒**（`medicine-edit.ts` 新增 `discardUnfinishedPhotoDrafts`）：药品保存成功（新建/编辑/照片补传完成）时，把队列里与本份保存无关的未完成草稿（review/recognizing/failed）标记 `cleanup_pending` 并异步清理文件；`photo_pending`（照片待补）草稿保留以支持重试。此前行为是只清当前草稿、旧草稿永久提醒"导入草稿"。
2. **录入按钮放大**：首页"录入家里的药"选择面板（拍照/相册/手动/扫码）padding 22→30rpx、图标 66→80rpx、标题 29→33rpx、提示 21→24rpx；录入页"拍药盒/从相册/扫码/保存"按钮 min-height 88/80→104rpx、字号 32rpx。
3. **追溯码提取商品码**（`barcode-parser.ts`，见决策记录）：无分隔符长数字串优先按 AI(01)+14 位、其次按"前 14 位即 GTIN-14"读取，**仅当 GTIN 校验位通过**才提取商品码查询候选；01+商品码+17 有效期+21 序列号（无括号）现在可解析，序列号不回填批号。校验不过仍按追溯码保留原码，不猜测内部片段。
4. **单位预填**（`unitIndexFromText` + `prefillBatchUnit`）：识别/候选的规格文本（"3克×10袋""0.3g×20粒""10ml×6支"）按最后一个非"盒"单位关键词预填批次单位（袋/粒/支等）；仅当用户未改过单位、数量为空且当前为默认"盒"时生效；手动切换单位即标记 touched，后续候选不覆盖。
5. **新增"抗感染"用途标签**（`antiinfective`，值域第 15 个）：contracts/inputs 白名单、API 标签文案、小程序/Flutter 标签映射、识别双 prompt、资料库关键词映射（消炎/抗感染/抗菌/抗生素/细菌感染/敏感菌）全链路加入；**刻意不含"抗炎"**——布洛芬等 NSAID 的"抗炎"不得映射为抗感染（有测试固定）。
