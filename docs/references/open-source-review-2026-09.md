## 外部资料来源候选

- [阿里云百炼视觉理解文档](https://help.aliyun.com/zh/model-studio/vision)：候选中文视觉识别服务。模型可用地区、图片大小、价格、保留政策和真实药盒准确率须在 P2 实测；密钥只在后端。
- [极速数据药品信息 API](https://www.jisuapi.com/api/medicine/)：页面描述可按名称、厂家、批准文号或条码查询；资料和说明书并不覆盖所有药，页面特别说明处方药说明书不提供。需确认账号套餐、隐私政策、商用授权和字段匹配能力。药品没找到时保留手动录入路径。
- [中国药品批文库 API 说明](https://open.bcpmdata.com/api/12.html)：另一商业候选，有批准文号与说明书字段；API 需要 key。只登记为备用调研项，不把任何接口当作已购买或已接通。

## 使用原则

1. 记录原始来源 URL、核查时间、文件 SPDX 标识或 `UNLICENSED` 状态。
2. 使用开源依赖时通过 lockfile 固定完整解析版本、保留 package provenance，并按依赖许可证生成 notices。
3. 本项目参考文档、合成资料与实现保持独立；没有另行书面授权时，不复制参考项目代码和视觉素材。
4. 药品资料 API 的合同许可与数据正确性是两项不同验证；接口返回不代表临床适用或个人处方。
